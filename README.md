# Vibe Radar

面向中文 AI builder 的每日新品策展项目：从多源发布事件中筛选值得体验的产品，提供有依据的体验指引，并通过读者反馈改进精选。

当前仓库处于需求与验证准备阶段，已整理产品文档和申报材料；采集管线、网站与分发功能尚待实现。

## 文档入口

| 文档 | 用途 |
|---|---|
| [完整 PRD v1.1](PRD.md) | 用户与范围、九个模块、数据接口、发布流程、评测与验收 |
| [PRD 评审建议](docs/reviews/PRD_REVIEW.md) | 原稿问题、修订理由、优先级与待确认事项 |
| [原版 PRD v1.0](docs/archive/PRD-v1.0.md) | 保留原始设计与历史参考，不作为最新实施基线 |
| [项目申报书](docs/proposals/项目申报书.docx) | 原始申报材料，部分指标与表述需按最新 PRD 同步 |

建议先读评审建议，再读 PRD 第 3、5、13、15 章，确认首发范围、发布规则、阶段验收与启动准备。

## 首发建议

- 中文内容，网页阅读与匿名反馈，飞书作为首发分发入口。
- 常规每期 5–8 条，默认 6 条；质量不足时短刊，不凑数。
- 区分直接试玩、观看演示、安装体验，明确登录、付费与安装门槛。
- 先完成 HN、GitHub 与人工候选的端到端验证，PH 接入条件满足后启用。
- 每日北京时间 09:00 发布；先验证读者试玩与回访，再研究排序学习和个性化。

以上为 PRD 的建议默认值，正式上线参数仍需项目负责人确认。
