## 验收发现并修复

1. 清理会话会覆盖失败状态，导致配方成功率失真。保留失败/超时终态及原始结束时间，统计同时识别既有失败事件。
2. 试玩停止后仍按墙钟累积“就绪 30 秒”。改为按实际就绪至停止/到期的时间判断，页面和反馈 API 使用同一证据条件。
3. SSE 代理返回错误的内容类型。保留上游 SSE 类型、检查会话虚拟密钥，并修正 Anthropic SDK 的基础路径。
4. 复用富化结果可能绕过垃圾内容拦截。重新执行当前分类资格与严格模式检查。
5. 预算只检查当前余额，最后一次或并发调用可能越过上限。网络请求前原子预留预计成本及重试余量，结束后按实际用量结算；未知失败保留估算预留。
6. 管理接口仅依赖部署边界，容器或 LAN 可接触模型设置。增加本机地址与 Host 校验，其他客户端需独立管理令牌；本机写操作校验同源。
7. Docker 清理失败仍可能标记资源已回收。现在撤销虚拟密钥并保留待清理状态与工作区，便于重试。
8. 修复无 JS 冷却反馈、未来条目展示和英文试玩指南混排；guided 页面只显示已提供的本地指南。

未定价模型仍遵循项目既有策略：普通 Gateway 记零成本并标注，硬预算仅保证已定价模型。试玩模型代理拒绝未定价模型。上述测试不构成真实提供商价格或账单的核验。
