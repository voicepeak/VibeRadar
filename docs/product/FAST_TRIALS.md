# 快速试玩候选准入建议

优先把依赖预装到固定镜像，再按实际等待时间选择首期开放的工具。MarkItDown 基础转换已有本机对照：原始安装方式 83.806–96.249 秒，预装就绪后 3.010–4.615 秒；详见 [真实计时记录](../implementation/TRIAL_TIMING_2026-10-14.md)。其他工具尚未取得同等实测数据，不能据此推断它们的启动速度。

以下是候选筛选建议，尚未变成自动强制门槛；30 秒是产品准入目标，不是对用户的启动保证。

| 条件 | 快速试玩候选 | 其他体验方式 |
| --- | --- | --- |
| 依赖准备 | 已提供核验过的固定摘要镜像；启动时不安装依赖 | 缺少构建产物时提供安装指南 |
| 启动耗时 | 至少三次缓存就绪启动，每次 30 秒内可用，并校验实际功能 | 超过门槛继续提供在线演示或指南 |
| 首次成本 | 单独记录下载、准备时间及传输体积；启动结果不能代替首次下载测试 | 未测量时明确标注首次准备时间未验证 |
| 模型与资源 | 样例可在既定资源限额内运行；需要模型时只用核验过的代理 | 需额外模型下载、硬件或账户配置时给出对应说明 |
| 配方核验 | 固定版本、许可检查、真实隔离与回收通过 | 未核验维持 guided，不开放执行 |

减少可选依赖时应说明能力范围，例如只开放 HTML 转 Markdown，PDF/Office/OCR 不在该试玩样例内。只按“镜像小”或“看起来简单”判断不能替代实测。

产品入口保留发现、在线体验和指南；快速试玩可作为其中一个已验证入口。首期不要求所有推荐工具都有本地试玩配方，也不因为试玩速度改变 Feed 的推荐排序。

主程序与试玩镜像分开发行，按用户选择下载镜像，不在主程序里捆绑全部工具环境。
本机 MarkItDown 测试镜像归档实测为 107.78 MB，展开 432.24 MB；缓存占用和首次下载体积都应纳入候选筛选。
